# 逐句阅读器

一句一屏地读 Markdown / EPUB / TXT。当前句大字显示，前后句淡色提示，按空格翻页——像看字幕一样读书。

**在线使用：** https://wangbrightly.github.io/sentence-reader/

**安卓 App：** 到 [Releases](https://github.com/wangbrightly/sentence-reader/releases) 下载最新的 `sentence-reader-v*.apk`

## 用法

打开页面，把 `.md`、`.epub` 或 `.txt` 文件拖进窗口（或点「打开文件」）。

| 操作 | 按键 |
|---|---|
| 下一句 / 上一句 | `空格` `→` / `←`，或点屏幕右半边 / 左半边 |
| 下一章 / 上一章 | `]` / `[`，或用顶部章节下拉框 |
| 开头 / 结尾 | `Home` / `End` |
| 自动播放 | `P`（停留时间按字数计算，速度可调；插图停 3 秒） |
| 搜索 | `/` 或 `Ctrl/⌘+F`，或点顶栏「🔍 搜索」 |

**手机上**（安卓 App 和手机浏览器）：底部是「菜单 · 上一句 · 自动播放 · 下一句」四个按钮，菜单里有搜索、进度滑轨、自动播放速度、跳到第 N 句、章节、打开文件；浅色 / 深色跟随系统设置。

**插图**：EPUB 里的插图、图表、封面单独占一屏，图片说明显示在下方；书里用图片代替的生僻字、小图标留在句子里，和文字一样大。

**搜索**：在当前这本书里找关键词（正文、章节标题、插图说明都能搜到，英文不分大小写），点一条结果跳过去，关键词标色，用 ‹ › 在结果之间跳；会记住最近搜过的 8 个词。

会记住上次读的书和读到哪一句，下次打开直接续读。

## 隐私

整个阅读器只有一个 HTML 文件，没有服务器，也不联网。书的内容、阅读进度和搜索记录只在你自己的浏览器（或手机）里解析和保存，不会上传到任何地方。安卓 App 不申请任何权限。也可以下载 `index.html` 到本地双击使用。

## 局限

- EPUB 插图会显示；Markdown 里的图片只显示图片说明；公式和注释链接会丢失
- 按标点断句，`Dr.` 这类英文缩写偶尔会被误切
- 不支持带 DRM 加密的 EPUB
- 深色模式下，书里用图片代替的生僻字会显示成白底小方块（图片自带白底）
- 搜索不区分大小写，但区分全角 / 半角（搜 `ABC` 找不到 `ＡＢＣ`）

## 开发统计（截至 2026-10-10，v0.1.4）

- **代码量**：2106 行（网页版 `index.html` 815 行，其中样式 211 行、脚本 481 行；Kotlin 主代码 249 行、Kotlin 单元测试 155 行、网页端 Puppeteer 测试 685 行、XML 97 行、Gradle 脚本 92 行、打包脚本 13 行），另有 54 行 DEV_WORKFLOW.md 开发进度与踩坑记录。自动化测试共 77 个（网页 52 个、安卓 25 个）。
- **提交次数**：21 次（10-08：6 次，10-09：11 次，10-10：4 次），发布 5 个版本（v0.1.0～v0.1.4）。首版网页没有自动化测试；从安卓版起，每个改动都先写测试、确认失败、再写实现（红绿在同一次提交里，提交记录里看不出配对），每次发版前真机验收。累计新增 2443 行、删除 105 行——删除量很少，因为返工大多发生在提交之前（比如中文粗体在真机上加不粗、改用描边模拟；插图功能用真书实测后，才发现古籍里几千张小图是生僻字，改成留在句子里）。
- **开发时长**：约 8.6 小时，跨 2026-10-08 至 2026-10-10 三天（按开发对话的消息时间戳估算：相邻消息间隔 ≤90 分钟计入连续工作时间，超过按休息处理，此为估算方法，非精确计时；若按提交时间戳估算只有 4.5 小时，因为提交稀疏、一次提交前常连续工作数小时，会严重低估）。
- **对比人工独立开发**：本项目是一个零依赖的单文件阅读器网页（Markdown / EPUB 解析、按中英文标点切句、EPUB 插图与句内生僻字图片、书内搜索、自动播放、手机界面与深浅色）加安卓 WebView 外壳（文件选择与「用…打开」、返回键、屏幕常亮、正式签名发布），以界面与平台对接为主，估算约 200～300 行/日"测试通过、真机验证过"的代码。按净新增约 2100 行估算，传统手写方式约需 **7～11 个工作日**；AI 辅助后实际耗时约为其 1/7～1/10（未计入界面设计稿的制作时间）。此项为估算，非精确测量。

## 安卓版

`android/` 目录是安卓 App：WebView 直接显示本仓库的 `index.html`（每次编译自动复制进去），所以网页版的功能 App 里都有。App 另外支持：文件管理器里「用…打开」md/epub/txt、打开文件时只列出这三种格式、返回键先收起菜单 / 搜索、自动播放时屏幕常亮。

**下载安装：** 到 [Releases](https://github.com/wangbrightly/sentence-reader/releases) 下载最新的 `sentence-reader-v*.apk`，在手机上打开安装（需允许「安装未知来源应用」）。

自己编译：

```sh
cd android
JAVA_HOME=/usr/local/opt/openjdk@21 gradle testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

网页端测试（手机界面、插图、搜索、解析，以及电脑版界面逐像素不变）：`node --test --test-concurrency=1 tests/*.test.mjs`（需要本机装有 Puppeteer；逐个文件跑，同时跑会让像素比对偶发误报）。
